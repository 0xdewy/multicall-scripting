# Ticket H3 — Return-data chaining is the verification bottleneck (bytecode-level only)

**Claim:** Data-dependent return-data chaining defeats source-level and static-abstraction
analyzers; sound verification tractable only at bytecode-semantics (KEVM) level.

**What would settle it:** whether corpus bytecode tools (KEVM, Isabelle/HOL, eThor) handle
data-dependent dispatch that source-level tools (solc-verify) cannot — or whether all fail.

**Status:** unclaimed → proponent + falsifier + rebuttal in 04-evidence/.
